# Typography ภาษาไทยสำหรับงาน UI

อ่านไฟล์นี้เมื่องานมีภาษาไทย กฎ typography ที่มาจากงานฝรั่งหลายข้อใช้กับไทยไม่ได้ และเป็นสาเหตุที่งานไทยจำนวนมากดูราคาถูกทั้งที่ layout ดี

## สิ่งที่ทำให้งานไทยพัง (แก้ก่อนอย่างอื่น)

| ปัญหา | เกิดจาก | แก้ |
| --- | --- | --- |
| สระบน/ล่างชนกันระหว่างบรรทัด | ใช้ line-height แบบฝรั่ง (1.2–1.4) | ไทยต้องการ **1.6–1.9** สำหรับเนื้อความ, หัวข้อใหญ่ไม่ต่ำกว่า 1.25 |
| ตัวหนังสือดูแน่นอ่านยาก | `tracking-tight` / letter-spacing ติดลบ | ไทย **ห้ามบีบ letter-spacing** ค่า 0 คือค่าที่ถูก จะขยายเล็กน้อยได้เฉพาะตัวเล็กมาก |
| ALL CAPS ใช้ไม่ได้ | ไทยไม่มีตัวพิมพ์ใหญ่ | เน้นด้วยน้ำหนัก ขนาด สี หรือระยะห่างแทน (เป็นข้อดี เพราะ eyebrow ALL CAPS คือลายเซ็น AI อยู่แล้ว) |
| ไทยดูเล็กกว่าอังกฤษเมื่ออยู่บรรทัดเดียวกัน | ฟอนต์ไทยหลายตัวมี x-height ต่างจากคู่ละติน | เลือกฟอนต์ไทยที่มีคู่ละตินในตระกูลเดียวกัน หรือปรับ `font-size-adjust` / ขนาดแยก |
| ตัดคำผิดกลางคำ | เบราว์เซอร์ตัดคำไทยไม่เก่ง | ใส่ `word-break: break-word` อย่างระวัง, ใช้ `lang="th"`, หลีกเลี่ยง `text-align: justify` |
| ข้อความล้นปุ่ม | ไทยยาวกว่าอังกฤษ ~15–30% | ออกแบบปุ่ม/label เผื่อความยาว อย่า fix ความกว้างตามข้อความอังกฤษ |

เพิ่มเติม: อย่าใช้ `text-transform: uppercase` กับข้อความที่ปนไทย, ระวังฟอนต์ไทยที่ไม่มีน้ำหนักครบ (จะโดนเบราว์เซอร์ปลอมตัวหนาให้ แล้วสระเบี้ยว) — ตรวจว่าฟอนต์มีน้ำหนักที่จะใช้จริง

## ผสมไทย-อังกฤษ

ประกาศไทยไว้ก่อนในลิสต์เสมอ เพื่อไม่ให้ฟอนต์ละตินไปเรนเดอร์ตัวไทยเพี้ยน:

```css
font-family: "IBM Plex Sans Thai", "IBM Plex Sans", system-ui, sans-serif;
```

หลักการเลือกคู่:
- คู่ที่ปลอดภัยที่สุดคือฟอนต์ที่ออกแบบมาเป็นตระกูลเดียวกัน (IBM Plex Sans Thai + IBM Plex Sans, Noto Sans Thai + Noto Sans)
- ถ้าจับคู่ข้ามตระกูล ให้เทียบ x-height, ความหนาของเส้น, และความกว้างตัวอักษรให้ใกล้กัน มองที่คำที่มีทั้งไทยและอังกฤษในบรรทัดเดียว
- ตัวเลข: เลือกใช้เลขอารบิกให้สม่ำเสมอทั้งงาน (เลขไทยใช้เฉพาะเมื่อบริบทเรียกร้องจริง เช่น เอกสารราชการ) และใช้ `tabular-nums` ในตาราง

## ค่าเริ่มต้นที่แนะนำ

```css
:root { --line-body: 1.75; --line-heading: 1.3; }

body {
  font-family: "IBM Plex Sans Thai", system-ui, sans-serif;
  font-size: 16px;          /* ไทยไม่ควรต่ำกว่า 15px บนจอ */
  line-height: var(--line-body);
  letter-spacing: 0;        /* ห้ามติดลบ */
  -webkit-font-smoothing: antialiased;
}

h1, h2, h3 { line-height: var(--line-heading); letter-spacing: 0; }

/* ตัวเล็กมากต้องใหญ่ขึ้นและหายใจมากกว่าฝรั่ง */
.caption { font-size: 14px; line-height: 1.7; }
```

ความยาวบรรทัด: ไทยอ่านสบายราว 50–70 ตัวอักษรต่อบรรทัด กว้างกว่านั้นสายตาหาบรรทัดถัดไปยากเพราะไม่มีช่องว่างระหว่างคำมาช่วย

## ตรวจก่อนส่งงานไทย

1. ซูมดูจุดที่มีสระบน+วรรณยุกต์ซ้อน (เช่น "เชื้อ", "ที่", "หนึ่ง") — ชนบรรทัดบนไหม
2. ลองข้อความยาวสุดที่เป็นไปได้ในทุกปุ่มและ label — ล้นไหม ตัดคำถูกไหม
3. ดูบรรทัดที่ปนอังกฤษ — ขนาดสองภาษาดูเท่ากันไหม
4. เช็คน้ำหนักตัวหนา — เป็น bold จริงจากฟอนต์ หรือเบราว์เซอร์ปลอมให้
5. บนมือถือ ตัวเล็กสุดในหน้ายังอ่านออกไหม
