# ทีมและการมอบงาน

agent ทุกตัวเริ่มจากศูนย์ ต้องอ่านโค้ดใหม่ และคำขอของมันนับเข้าโควตาเพิ่มจากเซสชันหลัก ส่งเมื่อคุ้มเท่านั้น ถ้าเซสชันหลักทำได้ในไม่กี่ไฟล์ ให้ทำเอง

| บทบาท | ใคร | ทำอะไร | ห้ามทำ |
| --- | --- | --- | --- |
| หัวหน้า | เซสชันหลัก: Sonnet สำหรับงานทั่วไป, Opus เฉพาะสเปกและดีไซน์ระดับเต็ม | ทวนโจทย์ วางแผน เขียนโค้ดระดับเบาและกลาง ตรวจ diff รายงาน | เชื่อคำว่าเสร็จของ agent โดยไม่ตรวจ |
| `scout` | Haiku, effort low | สำรวจโค้ดหรือย่อ log ส่งสรุปสั้นพร้อม path:บรรทัด | แก้ไฟล์ |
| `implementer` | Sonnet, effort medium (high เมื่อ slice ยาก) | ทำ slice เดียวตาม brief รัน test commit ส่งหลักฐาน | ทำนอก brief |
| `reviewer` | Sonnet, effort high งานเงิน/auth/ข้อมูลจริงส่ง `model: opus` ห้ามแก้ไฟล์โปรเจกต์ (บังคับด้วย prompt ตรวจ `git status` หลังมันจบ) | ได้แค่สเปก + diff พยายามทำให้พัง รายงานเฉพาะที่พิสูจน์ด้วยการรัน | ดูแชทของ implementer, แก้โค้ด |

**effort:** high กับงานที่ผิดแล้วแพง medium/low กับงานที่ brief ชัดหรืองานอ่านค้น ขยับ implementer เป็น high เฉพาะ slice ที่ซับซ้อน (concurrency, migration, เงิน, auth) ถ้าตั้ง env `CLAUDE_CODE_EFFORT_LEVEL` ไว้ ค่านั้นจะทับ effort ในไฟล์ agent

**วิธีเรียก (ลองตามลำดับ):**
1. เรียกตามชื่อ `implementer`, `reviewer`, `scout` (ถ้าระบบแสดงพร้อม prefix เช่น `agentic-engineering:implementer` ให้ใช้ชื่อนั้น)
2. เรียกไม่ได้ ให้ใช้ agent ทั่วไป ระบุ `model` ตามตาราง แล้ววางกติกาจาก `references/agents.md` ไว้หัว brief สั่ง reviewer ชัด ๆ ว่าห้ามแก้ไฟล์
3. เรียกไม่ได้เลย หัวหน้าทำเอง แต่ระดับเต็มต้องบอกผู้ใช้ว่ายังขาดการตรวจอิสระ

**กติกา:**
- **brief ครบในตัวแต่สั้น** agent ไม่เห็นแชทหลัก ใส่: เป้าหมายของผู้ใช้, ไฟล์ที่แตะได้/ห้ามแตะ, รูปร่างข้อมูล, เกณฑ์เสร็จ, คำสั่ง test ชี้ไปที่ไฟล์ ไม่แปะเนื้อหายาว
- **สั่งต่อตัวเดิมถ้ามันมี context ที่ยังใช้ได้** ถูกกว่าเริ่มตัวใหม่ เริ่มตัวใหม่เมื่อตัวเดิมหลงทางหรือจบไปนานแล้ว พร้อมบอกงานเดิมและ branch
- **ผู้ตรวจต้องไม่ใช่ผู้เขียน** context ที่สะอาดคือประโยชน์หลัก ถ้าคุ้มให้ใช้คนละโมเดลด้วย
- **ขนานเมื่อผู้ใช้สั่งและงานแยกขาดจริง** แต่ละตัวต้องแยก worktree (`isolation: worktree`) ห้ามเขียนไฟล์เดียวกัน
- **หัวหน้าเป็นเจ้าของผลงาน** อ่าน diff เอง เขียนสรุปเอง "เสร็จแล้ว" จาก agent ไม่ใช่หลักฐาน
- รีวิวแยกไม่ได้ในระดับเต็ม ให้บอกผู้ใช้ว่ายังขาดขั้นนี้ หัวหน้ารันคำสั่งของทุกข้อค้นพบซ้ำก่อนเชื่อ
