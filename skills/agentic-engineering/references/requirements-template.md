# แม่แบบไฟล์รีไควร์เมนต์ (`docs/requirements/<ชื่องาน>.md`)

ไฟล์นี้คือ **แหล่งความจริงชุดเดียว** ของงาน ผู้ใช้กับ agent อ้างอิงที่นี่ ไม่อ้างแชท เพราะแชทหายเมื่อ `/clear` แต่ไฟล์อยู่ใน repo และ session ถัดไปอ่านต่อได้ทันทีโดยไม่ต้องเล่าใหม่ (ประหยัดโควตา)

กฎการเขียน:
- เขียนเป็นภาษาไทยธรรมดา ศัพท์เทคนิคใส่วงเล็บครั้งแรก
- ทุกข้อที่ทดสอบได้มีรหัส `REQ-<เลข>` และเกณฑ์ยอมรับ (acceptance criteria) ที่ตรวจได้ด้วยการกดหรือรันจริง ห้ามเขียน "ทำงานได้ดี" "ใช้งานง่าย"
- ไม่ใส่ path ไฟล์หรือโค้ดในส่วนรีไควร์เมนต์ เพราะเปลี่ยนเร็ว ใส่ได้เฉพาะส่วน "แผน"
- ห้ามแก้ข้อที่ผู้ใช้ยืนยันแล้วเงียบ ๆ ทุกการเปลี่ยนผ่าน "คำขอเปลี่ยน" และลง "ประวัติการเปลี่ยน"
- **ฉบับย่อ (ระดับกลาง):** ใช้เฉพาะหัวข้อ 1, 4, 5, 10, 11, 13, 14 และ 8 ถ้ามีหน้าจอ ลบหัวข้ออื่นทิ้ง ยาวราวครึ่งหน้า
- **ฉบับเต็ม (งานใหญ่ โปรเจกต์ใหม่ ระดับเต็ม):** ทุกหัวข้อ หัวข้อที่ไม่มีเนื้อหาให้เขียน "ไม่มี" แทนการลบ จะได้รู้ว่าคิดแล้ว
