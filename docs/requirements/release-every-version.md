# รีไควร์เมนต์: อัปเดต repo + release ทุกเวอร์ชัน + README

สถานะ: ยืนยันแล้ว (2026-11-28)
ระดับงาน: กลาง   ·   playbook: feature

## 1. ปัญหาและเป้าหมาย
- ปัญหาจากมุมผู้ใช้: repo ค้างที่ 0.11.0 ทั้งที่ตัวที่ใช้จริงไปถึง 0.15.0 ไม่มี tag หรือ release ให้ดาวน์โหลด และไม่มีอะไรเตือนเมื่อลืมออกเวอร์ชัน
- เสร็จแล้วใครได้อะไร: คนติดตั้งได้ไฟล์ `.plugin` ของทุกเวอร์ชันจากหน้า Releases เจ้าของ repo ขยับเลขแล้ว merge ก็ได้ release เองโดยไม่ต้องจำ
- วัดความสำเร็จ: ทุกเวอร์ชันที่มีสถานะใน git (0.7, 0.8, 0.9, 0.10, 0.11, 0.14, 0.15) มี release พร้อมโน้ตและไฟล์ `.plugin`

## 4. รีไควร์เมนต์ที่ต้องทำ

| REQ-1 | repo ตามทันตัวที่ติดตั้ง | `diff -rq` กับปลั๊กอินที่ติดตั้ง 0.14 และ 0.15 ไม่มีไฟล์ต่าง (ยกเว้นการแก้ที่ตั้งใจ) | ต้องมี |
| REQ-2 | merge เวอร์ชันใหม่เข้า main แล้วได้ release เอง | หลัง merge PR นี้ หน้า Releases มี v0.15.0 พร้อมไฟล์ `.plugin` และโน้ตจาก README | ต้องมี |
| REQ-3 | PR ที่ผิดกฎการออกเวอร์ชันต้องไม่ผ่าน CI | `scripts/check-release.sh` คืน exit 1 เมื่อ: แก้สกิลแต่ไม่ขยับเลข, ไม่มีโน้ต, SKILL.md ไม่ตรง, เลขลดลง, tag ซ้ำ | ต้องมี |
| REQ-4 | release ย้อนหลังของเวอร์ชันเก่า | v0.7.0 v0.8.0 v0.9.0 v0.10.0 v0.11.0 v0.14.0 มี tag ที่ commit ของเวอร์ชันนั้น | ต้องมี |
| REQ-5 | กฎเขียนไว้ให้คนและ AI อ่าน | `CLAUDE.md` บอกขั้นตอนออกเวอร์ชันและสิ่งที่ CI ตรวจ | ต้องมี |
| REQ-6 | README อ่านง่ายและติดตั้งได้จริง | มี badge, สารบัญ, วิธีติดตั้งจาก Releases, คำสั่ง marketplace ใช้ชื่อ repo ที่ถูก | ต้องมี |
