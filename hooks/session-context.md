[agentic-engineering] คุยกับผู้ใช้เป็นภาษาไทยเสมอ งานที่ไม่เกี่ยวกับโค้ดไม่ต้องใช้ส่วนที่เหลือ งานโค้ด: ก่อนแก้ไฟล์แรกให้จัดระดับ เบา = แก้ข้อความ สี ค่าคงที่ หรือจุดเดียวที่ระบุชัดและไม่เปลี่ยน logic ทำเองได้ไม่ต้องโหลดสกิล นอกนั้นทั้งหมด (บั๊ก ฟีเจอร์ รีแฟกเตอร์ เงิน auth ข้อมูล) ต้องเรียก Skill agentic-engineering แล้ว Skill learn-while-building ก่อนแก้ไฟล์แรก (ข้าม learn-while-building เมื่อผู้ใช้ปิดโหมดสอน) แล้วทำตาม SKILL.md งานเบายังต้อง: เขียนสั้นที่สุดที่อ่านออก ไม่มีโค้ดเผื่อ คอมเมนต์ฟังก์ชันที่เพิ่มหรือแก้ตาม references/code-quality.md รันของจริงก่อนบอกว่าเสร็จ ส่ง "เสร็จขั้นที่ x/y" เมื่อจบแต่ละขั้น จบด้วย "ทำอะไรไปบ้าง" (ไฟล์ ก่อน→หลัง ทำไม) commit หัวข้ออังกฤษ type(scope): subject body ไทย งานกลางขึ้นไป: อัปเดตบอร์ดกลาง Whiteboard ทุก slice ตาม playbooks/board.md (ยังไม่มีบอร์ดให้สร้างก่อนแก้ไฟล์แรก เซสชันไหนไม่มีเครื่องมือ artifact ให้อัปเดต docs/system-map.md จดค้างใน docs/board.md แล้วบอกผู้ใช้ ห้ามบอกว่าอัปเดตแล้วถ้าไม่ได้เขียนจริง) ทุกระดับ: บนคลาวด์ (CLAUDE_CODE_REMOTE=true) push branch งานก่อนจบ ห้าม push เข้า branch หลัก repo ของทีม (งานบริษัท ฝึกงาน มีคนอื่น commit ร่วม มี CONTRIBUTING.md หรือ CODEOWNERS) อ่าน playbooks/team-work.md ทุกระดับ กติกาทีมชนะเรื่องภาษาคอมเมนต์ commit PR และ style ลำดับเมื่อกฎขัดกัน: คำสั่งผู้ใช้ในแชท > กติกาทีม > agentic-engineering > สกิลอื่น
